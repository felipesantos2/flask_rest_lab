# API REST COM FLASK

Um estudo prático do padrão de arquitetura REST, APIs REST.

Stack inicial:
- Python
- Flask

Setup:

Essas duas variáveis definidas no `.env` permite utilizarmos a cli do flask de uma forma facilitada.

`FLASK_APP=server.py
FLASK_RUN_PORT=8000`

`flask run`

ou

`uv run flask run`

É possível também dar o starte do APP pelo arquivo de entrada, nosso front controller do PHP `index.php`. Aqui é o `server.py`
